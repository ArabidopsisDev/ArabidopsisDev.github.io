# 复习清单

生成式软件工程 / 1.2 从最简单的开发方式开始

当前项目支持每项内容独立勾选、取消，以及刷新后的状态恢复。保存失败时，页面会显示提示。两项内容标题相同，编号不同。

请将项目解压到自己的工作目录，通过本地静态服务器打开 index.html。如果你的电脑已经安装 Python，可以在该目录执行 `python -m http.server 8000`，再访问 http://localhost:8000。也可以使用编辑器的静态预览服务器。

当前项目使用本地存储名称 `gse-review-checklist-1-2`。请使用同一浏览器和同一地址检查保存功能。

请先检查现有勾选和保存功能，并保存一份原始代码，然后依次完成以下修改：

1. 增加“只看未完成”开关。打开时只显示未完成项，关闭时显示全部条目。过滤状态下，勾选完成的条目从当前列表中隐藏。全部完成时显示“没有待复习内容”。刷新后完成状态保留，开关恢复关闭。
2. 增加“待复习 N 项”，显示全部条目中未完成项的数量。勾选、取消和刷新后更新数量，过滤开关不改变数量。

请保留条目编号、现有完成记录和保存失败提示。提示词位于 prompts.txt。记录最终确认的功能要求、代码修改和实际检查结果，也记录无法完成的检查。

你可以在 requirements.md 中保存功能要求，在 checks.md 中保存检查步骤和结果；项目已有相应文件时，请更新原有文件。
