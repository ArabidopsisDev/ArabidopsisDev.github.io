# 复习清单

生成式软件工程 / 1.1 什么是软件过程

当前页面显示三项复习内容，还没有完成勾选和保存功能。两项内容标题相同，编号不同。

请将项目复制到自己的工作目录，通过本地静态服务器打开 index.html。如果你的电脑已经安装 Python，可以在此目录执行 `python -m http.server 8000`，然后访问 http://localhost:8000。你也可以使用编辑器提供的静态预览服务器。

检查保存功能时，请使用同一浏览器和同一地址。如果直接双击 HTML 文件打开，不同浏览器对本地存储的处理可能不同。

修改前，请先保存一份原始代码。这次需要实现以下功能：

1. 每项内容都可以单独勾选为完成，也可以取消。
2. 页面能够清楚地区分已完成和待复习的内容。
3. 在同一浏览器中刷新页面，或者重新打开同一地址时，之前的状态仍然保留。
4. 两项内容即使标题相同，也能分别勾选、保存和恢复状态。
5. 如果保存失败，页面仍然允许勾选和取消，并提示使用者记录未保存。

我们暂时只使用当前浏览器的本地存储，不增加账号、跨设备同步、条目编辑和复习时间安排。

完成后，请保留最终确认的功能要求、代码差异，以及每一步操作和实际结果的检查记录。你可以在 prompts.txt 中找到实践提示词，正文位于 https://arabid.top/courses/generative-software-engineering/1-1-software-process.html 。
