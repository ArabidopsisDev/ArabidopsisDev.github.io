# 导入复习进度

生成式软件工程 / 1.4 用快速原型确认需求

请通过本地静态服务器打开 index.html，也可以直接打开文件。页面使用预先写在程序里的进度数据，操作结果只保存在页面内存中，刷新后恢复初始状态。文件读取和浏览器存储需要在后续开发中接入。

页面可以调整当前进度、选择两组待导入进度、比较替换与合并、查看逐项变化，以及确认或取消。打开预览期间，当前记录和导入选项暂时不能修改；取消后可以继续调整。

本机初始状态只有 r001 已完成，其余两项未完成。第一组待导入进度只有 r002 已完成，其余两项未完成。选择替换并确认后，本机应只有 r002 已完成。恢复初始状态再选择合并并确认后，r001 和 r002 都应完成，r003 应保持未完成。

试用前，请先问使用者希望保留哪些记录，再请他自己选择导入方式，并在确认前说出各项会变成什么状态。如果他的预期与页面结果不同，请问他怎样理解所选的操作；如果他已经理解结果，却仍然无法保留想要的进度，就继续讨论需要怎样修改导入规则。

请记录使用者实际选择的选项、确认或取消的操作，以及他的原话。自己的猜测另行记录，不能把猜测当作对方说过的话。修改页面或规则以后，还需要再次请人试用；没有进行的试用不要填写结果。

提示词位于 prompts.txt。修改前请保存原始代码，不要将原型接入正在使用的清单存储。
