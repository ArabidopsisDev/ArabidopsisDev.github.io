## 运行上传实验

在解压目录打开终端，运行：

```sh
python -m http.server 8093
```

浏览器访问 http://localhost:8093/upload-lab/ 。
如果端口已经被占用，可以改用其他空闲端口。

实验中的本机与共享记录保存在页面内存中，刷新会恢复初始状态。
你可以观察提交被拒绝以后本机修改怎样保留。
如果准备把这些操作用于日常复习，还需要在自己的清单项目中实现冲突合并，并通过实际网络请求验证服务端能否正确保存进度。

prompts.txt 与课程 1.9 的三段提示词一致。
实际结果在运行以后填写，未执行的工作保留为待执行。
